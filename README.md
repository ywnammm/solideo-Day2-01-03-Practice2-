## 주요 기능

### 1. 실시간 교통 정보 통합
- **기차** (KTX, 새마을호, 무궁화호)
- **버스** (고속버스, 시외버스)
- **비행기** (국내선 항공편)
- **렌터카** (자차 여행)

각 교통수단별 실시간 요금, 소요 시간, 편의성을 비교하여 최적의 선택을 제공합니다.

### 2. Google Maps 경로 시각화
- 출발지에서 목적지까지의 실제 경로를 지도에 표시
- 대중교통 경로 안내
- 거리 및 소요시간 계산

### 3. 비용 최적화
- **최저 비용 모드**: 가장 저렴한 옵션 우선
- **최단 시간 모드**: 가장 빠른 경로 우선
- **균형 모드**: 비용과 시간의 최적 밸런스
- 취소표 및 할인권 실시간 반영

### 4. 취향 맞춤 추천
#### 관심사별 추천
- 역사/문화
- 자연/풍경
- 맛집 탐방
- 쇼핑
- 액티비티
- 사진 명소

#### 음식 취향
- 한식
- 해산물
- 카페
- 로컬 맛집
- 파인 다이닝

#### 예산 범위
- 경제적 (₩50,000/박)
- 보통 (₩80,000/박)
- 여유 (₩150,000/박)
- 럭셔리 (₩300,000/박)

#### 여행 스타일
- 여유롭게 (하루 3-4개 일정)
- 적당히 (하루 4-5개 일정)
- 알차게 (하루 6개 이상 일정)

### 5. Day별 상세 일정
- **시간대별 활동**: 아침, 점심, 오후, 저녁까지 세분화
- **장소별 정보**: 각 방문지의 상세 정보와 추천 사유
- **소요 시간**: 각 활동별 예상 소요 시간
- **비용 정보**: 활동별 예상 비용

### 6. 종합 비용 분석
```
✓ 교통비 (왕복)
✓ 숙박비
✓ 관광/체험 비용
✓ 식비 (식사 + 간식)
✓ 총 예상 비용
```

## 화면 구성

### 1. 기본 정보 입력
- 출발지 (건물/역/공항)
- 도착지 (건물/역/공항)
- 출발 시간
- 여행 기간 (일)

### 2. 여행 취향 설정
- 관심사 선택 (다중 선택 가능)
- 음식 취향
- 예산 범위 슬라이더
- 여행 스타일 (여유/적당/알차게)

### 3. 교통 옵션
- 선호하는 교통수단 선택
- 최적화 방식 (시간/비용/균형)
- 할인 옵션 포함 여부

### 4. 결과 대시보드
- **요약 카드**: 총 소요시간, 예상 비용, 이동거리, 방문 장소 수
- **경로 지도**: Google Maps로 시각화된 이동 경로
- **교통수단 비교**: 선택 가능한 모든 교통수단의 상세 비교
- **일일 일정표**: Day 1, Day 2... 형식의 타임라인
- **비용 상세**: 항목별 비용 분석표

## 설치 및 실행

### 1. 프로젝트 클론
```bash
git clone [repository-url]
cd solideo-Day2-01-03-Practice2-
```

### 2. Google Maps API 키 설정
1. [Google Cloud Console](https://console.cloud.google.com/)에서 API 키 발급
2. `index.html` 파일에서 API 키 교체:
```html
<script src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&libraries=places,geometry,directions"></script>
```
**YOUR_API_KEY**를 실제 발급받은 API 키로 교체하세요.

### 3. 웹 서버 실행
로컬에서 테스트하기 위해 간단한 HTTP 서버를 실행하세요:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (http-server 설치 필요)
npx http-server -p 8000
```

### 4. 브라우저에서 접속
```
http://localhost:8000
```

## 사용 방법

### Step 1: 기본 정보 입력
1. **출발지** 입력 (예: 서울역)
   - 자동완성 기능으로 빠른 입력
2. **도착지** 입력 (예: 부산역)
3. **출발 시간** 선택
4. **여행 기간** 설정 (1-30일)

### Step 2: 취향 설정
1. **관심사** 선택 (복수 선택 가능)
   - 역사/문화, 자연/풍경, 맛집, 쇼핑 등
2. **음식 취향** 선택
   - 한식, 해산물, 카페, 로컬 맛집 등
3. **예산 범위** 조절
   - 슬라이더로 경제적 ~ 럭셔리 선택
4. **여행 스타일** 선택
   - 여유롭게 / 적당히 / 알차게

### Step 3: 교통 옵션 설정
1. **교통수단** 선택 (복수 선택 가능)
   - 기차, 버스, 비행기, 렌터카
2. **최적화 방식** 선택
   - 최단 시간 / 최저 비용 / 균형
3. **할인 옵션** 체크
   - 취소표 및 할인권 포함 여부

### Step 4: 일정 생성
"여행 계획 생성하기" 버튼 클릭

### Step 5: 결과 확인 및 저장
1. 생성된 일정 검토
2. 교통수단 비교 및 선택
3. 일일 일정표 확인
4. 비용 분석 확인
5. **저장** / **공유** / **인쇄**
